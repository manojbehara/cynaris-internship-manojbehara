# Modern JavaScript Array Tools

An interactive employee directory demonstrating ES6+ JavaScript features:

- `filter()`, `map()`, and `reduce()` on employee data
- Object and array destructuring
- Spread syntax and template literals
- `Set` for derived department values
- Event listeners for search, department filtering, sorting, and reset actions

## Run locally

From this directory, start a static server:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.
